# ==============================================================================
# PLANTATION - DEPENDENCIES LIST
# System: Pure Python 3.11, SQLite 3, HTML5, CSS3, and HTMX 2
# ==============================================================================

1. fastapi
   - Purpose: Asynchronous web framework for high-performance HTTP endpoints,
     HTMX partial rendering, and REST routing.

2. uvicorn
   - Purpose: Lightning-fast ASGI web server implementation powering FastAPI.

3. python-multipart
   - Purpose: Multipart/form-data streaming parser for multi-photo uploads up to 10MB.

4. weasyprint
   - Purpose: PDF-1.4 standard rendering engine converting HTML/CSS botanical cards
     and photo galleries into dark-mode dossier PDF documents on demand.

5. pillow (PIL)
   - Purpose: Image verification, metadata extraction, resizing, and format validation.

6. pillow-heif
   - Purpose: High-efficiency image format (AVIF/HEIF) decoding and container support.

7. sqlite3 (Python Standard Library)
   - Purpose: Embedded relational database engine for zero-configuration, robust local storage.
